# 99Knights 2D

A browser-based 2D arcade roguelite with a 27-room delivery journey, three boss encounters, bilingual Chinese/English dialogue, illustrated story scenes, and local-only playtest reporting.

## Play

After GitHub Pages is enabled, the game will be available at:

**https://bigonewd.github.io/99Knights-2D-/**

## Controls

- **Move:** `W A S D`
- **Light attack:** `J` or left mouse button
- **Heavy attack:** `K`, middle mouse button, or Shift + left mouse button
- **Guard / early parry:** `L` or right mouse button
- **Execute staggered enemy:** `E` or right mouse button
- **Dodge:** `Space`
- **Show hitboxes:** `H`

## Notes

- Runs entirely in the browser.
- No backend or account is required.
- Playtest data remains local unless the player explicitly downloads or copies a report.
- The game is distributed as a self-contained `index.html`.
